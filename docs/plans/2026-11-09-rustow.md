# rustow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use /subagent-driven-development (recommended) or /executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `rustow`, a Stow-compatible dotfiles linker in Rust with Tuckr-style status/visualization UX.

**Architecture:** Single crate, lib + thin bin. A plan/apply two-phase linker core (`link.rs`) is wrapped by a clap CLI. Config (`config.rs`) resolves precedence CLI → env → config.toml → stowrc with a provenance prompt. Status/create/diff are separate modules. All filesystem effects are computed in a plan first, then applied atomically-ish (nothing on conflict abort).

**Tech Stack:** Rust 1.99.0, edition 2024; clap 4 (derive), serde + toml + serde_json, schemars, shellexpand (stowrc `$VAR`), globset, regex (built-in stow ignore list), walkdir, tabled, owo-colors, dialoguer, thiserror, dirs; dev: tempfile, assert_cmd, predicates.

**Spec:** `docs/spec.md` (confirmed 2026-11-09)

## Global Constraints

- Binary and crate name: `rustow`; Rust 1.99.0; edition 2024.
- Link semantics must match the spec exactly: fold/unfold/refold; two-phase conflicts; idempotent relink; never touch non-owned paths without an explicit user decision.
- `config.toml` has **no default `source`** — error out until set. `.stowrc` is a fallback used only when no config.toml exists.
- Env vars: `DOTFILES_DIR` (source), `DOTFILES_TARGET` (target).
- Built-in ignore list = GNU Stow 2.4.1's list copied verbatim from `references/stow/default-ignore-list`.
- Diff tool precedence: `diff_tool` config → PATH-detected registry (cached in `$XDG_CACHE_HOME/rustow/diff-tool`) → `$EDITOR` both-buffer fallback. Helix deliberately excluded.
- Status table columns: `Package | Status | Notes`; statuses `linked|partial|unlinked|conflict`; exit 0 iff all inspected clean.
- All tests run against tempdir fake `$HOME`s; never against the real `$HOME`; `cargo test` must pass on a clean machine.
- `maskfile.md` is the task runner; `$MASK` chaining; conventional commits; `cargo fmt` + `cargo clippy -- -D warnings` clean.
- No script/cutover changes. Installation docs only.

## Review Focus

1. **Package with only ignored files** (e.g. only `.git`) — must not produce links nor crash; status shows `unlinked` with note, `link` is a no-op plan. (Task 5)
2. **Folded link blocks `unlink` of another package sharing the prefix** (e.g. `.config/foo` folded from pkg A; unlinking pkg B which needs `.config/` content) — refold must not produce a broken state. (Task 6)
3. **`config init` / provenance stamp in read-only or missing cache dir** — must warn/degrade gracefully, never panic. (Task 3, 10)
4. **`diff_tool` template with mismatched placeholders or shell quoting** (e.g. `diff_tool = "meld {left}"` or `= "echo '{left}'"`) — must fail with a clear message at merge time, not exec garbage. (Task 9)
5. **Two packages stow the same folded dir where one was already folded as real dir + rustow-owned symlink elsewhere** (unfold across pre-existing stow ownership) — fold/unfold must detect "owned" via resolved path, not basename. (Task 5)
6. **`status` on a package containing a dangling stow-owned link** — must count as linked-after-repair candidate or conflict per policy, not a crash. (Task 8)

### Task 5: Link planner (fold/unfold/conflicts), two-phase

**Files:**
- Create: `src/link.rs` (planner half)
- Test: `src/link.rs` unit tests (tempdir fixtures)

**Interfaces:**
- Consumes: Task 4 `Ignore`.
- Produces:
  - `pub fn scan_package(source: &Path, pkg: &str, ignore: &Ignore) -> Result<Vec<Entry>>` where `Entry { pkg_rel: PathBuf, abs_src: PathBuf, kind: EntryKind::{File, Dir, Symlink} }` (package symlinks are leaves, not followed; ignore applied to pkg_rel; empty dirs still yielded, folded links cover their contents).
  - `pub enum Action { Link { src, dst: PathBuf }, Fold { src_dir, dst }, Unfold { dst }, Repair { dst }, SkipIdempotent { dst }, Mkdir { dst } }`
  - `pub struct Conflict { pub dst: PathBuf, pub reason: ConflictReason, pub src: Option<PathBuf> }` with `ConflictReason::{Exists, ExternalSymlink, DanglingExternal, WrongPackage, DirFileMismatch}`
  - `pub struct Plan { pub actions: Vec<Action>, pub conflicts: Vec<Conflict> }`
  - `pub fn plan_link(source: &Path, target: &Path, pkgs: &[String], fold: bool, ignore: &Ignore) -> Result<Plan>`
- Planner rules (must match spec; the tricky three, copied from the spec):
  1. For a package dir D at pkg_rel `p`, target `dst`: if `!dst.exists() && !dst.is_symlink()` and fold → single `Fold` action covering the subtree (check subtree applies nothing more; ignored files are exposed via the folded link — stow behavior).
  2. If `dst` is a real dir → push `Mkdir` (if needed) and recurse into children (fold allowed deeper where clear).
  3. If `dst` is an existing symlink into `source` (any package, resolved absolute) whose target is a **dir** (folded link) and our candidate is also a dir → `Unfold` (remove the symlink, create real dir), then re-plan the folded package's subtree into it together with ours.
  4. Leaf: not exists → `Link`; symlink whose readlink == src → `SkipIdempotent`; dangling/this-package → `Repair`; into another package → `Conflict(WrongPackage)`; external → `Conflict(ExternalSymlink)`; real file/dir mismatches → `Conflict` (DirFileMismatch when dst is dir but entry is file, and vice versa).
  5. Multi-package runs aggregate into one `Plan`; conflicts collected, never applied when nonempty and policy != Overwrite/Adopt/Skip.

- [ ] **Step 1: Write failing tests** (fixtures built with tempfile):
  - `fold_when_target_missing`: pkg `eza` with `.config/eza/theme.yml`, empty `$HOME` → plan contains `Fold{dst: home/.config/eza}` after creating `Mkdir{.config}`; idempotent second plan is all `SkipIdempotent`/folded-skip.
  - `recurse_when_config_exists`: `$HOME/.config` exists as real dir → plan contains `Link{dst: .config/eza/theme.yml}` and no `Fold{.config}` (folds only inside the existing dir where clear).
  - `unfold_on_cross_package_dir_collision`: pkgA folded `.config/shared` (via running `link pkgA` first), then `link pkgB` where pkgB has `.config/shared/x` → plan contains `Unfold{.config/shared}` + `Link{x}`; applying it must leave both files reachable.
  - `conflict_real_file`: `$HOME/.config/app/conf` exists as real file; pkg has same → `Conflict{reason: Exists}`; plan applied → filesystem unchanged.
  - `conflict_external_symlink` and `conflict_wrong_package`; `dir_file_mismatch` both directions; `ignored_only_package_produces_empty_actions_no_crash` (Review focus #1 — `.git` only).
  - `dangling_link_into_package_repaired`.
- [ ] **Step 2:** `cargo test link::` → FAIL.
- [ ] **Step 3:** Implement planner exactly per rules; details: `is_owned_symlink(dst) = read_link(dst).map(resolve).map(|p| p.starts_with(source))` where readlink may be relative → absolutize against `dst.parent()`.
